# M7: world content

All values are trial settings. No environment art exists for any of these rooms; the rooms are geometry, cover, spawns and pickups only. The simulator was not touched.

## What was authored

Ten rooms went from generated placeholders to `authored` (overrides in `combat/rooms/overrides/`), plus geometry for the secret pocket. Each encounter id and its enemies match `combat/rooms/ENCOUNTER_CONTRACT.json`; the simulator worker implements them in parallel, so these rooms hold the data and the integrator adds runtime playthroughs after M6 lands. The expedition defaults table in `worldRunner.ts` still names only O1, O2, O3 and KT, so the new rooms stay empty at runtime until it is extended.

## Tests (`tests/worldContent.test.ts`, 10 tests; `tests/world.test.ts` unchanged and green)

Every authored room names exactly the contract's planned encounters with the contract's enemies in order; no elite pairs; the miniboss and boss fight alone in arenas of 700 units or more, and the boss arena has one door; spawns lie on open floor, face a real heading, stay 110 units apart (inside an encounter) and 110 from every door; cover exists in the ranged rooms; the line from the way in to the way out stays 80 units clear of cover (a 160-wide lane); solids stay inside the room and off the doorways; with every gate closed, camp still reaches the Watchpost, the High Gallery and the Ossuary, and each gate opens the room behind it; both key sources stay reachable in every gate state (doc 22 section 6); and each pickup is what its room's purpose line asks for. Totals: 149 unit tests pass.

## Findings

- The first layout had cover on several door-to-door lines (T2, S1, S2, S3, K2, K3). The lane rule is checked on the entry-to-exit line only, because T2 is a hub with four doors and a lane clear of cover for every pair does not exist there. Pairs of doors on perpendicular walls run along the wall at the corner, so the check skips 120 units at each end.
- The 110-unit spawn separation applies to the rooms authored here. The earlier authored pairs are closer: O1 `mireling2` stands 78 apart and O3 `mireling2` 74 apart. They were left as they were.
- The encounter contract sits in `combat/rooms/`, which `world:check` treated as a stray generated file. The checker now ignores that one file.
- In a full browser run on a busy machine the O1 zoom spec at 1280 by 720 failed once and passed alone; it measures camera timing and shares a machine with the other workers.
