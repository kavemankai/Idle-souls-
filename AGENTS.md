# Idle Souls implementation
Read CODEX_VISUAL_PRODUCTION_HANDOFF.md and the design library index before changes.
16_DECISIONS_AND_OPEN_QUESTIONS.md owns locks. L22/L23/L24 are binding: Blender-to-2D characters, fixed +75° orthographic camera, eight locomotion/guard facings, selective attacks with honest coverage. No mirroring asymmetric gear.
Ashen Reliquary appearance, scale and palette remain PROPOSED; record trial choices in docs/visual_proof/DECISIONS.md.
The authoritative combat source is combat/deep-stats/combat-sim.js (read combat/CLAUDE.md before changing it). `?scene=o1` renders it through src/world/o1Adapter.ts (source 'authoritative'); the controller in src/world/o1Controller.ts only walks the route and reads the simulator, it never picks a tactic. src/presentation/visualSequence.ts and the default scene stay VISUAL-ONLY fixtures, never tactical AI. Rendering consumes readonly contracts; do not invent damage, AI, hitboxes or timing to fit art. O1 geometry lives once, in combat/rooms/o1.json, and is shared by travel, sight, combat and drawing.
Run npm run lint, npm run typecheck, npm test, npm run build and npm run test:browser for runtime changes. Keep editable sources and reproducible exports. Do not mark human/device/combat QA passed without evidence.
Also run `node combat/deep-stats/tools/legacy-check.js` and `node combat/deep-stats/tools/regress.js` (both must print `different 0`) after touching the simulator, and `npm run report:o1` after changing O1 geometry, spawns or detection.
Rooms and links are generated: edit the CSVs or `combat/rooms/overrides/`, then run `npm run world:build`; `npm run world:check` must be clean. `tests/golden/o1-runs.json` guards O1 results: re-record it with `npx tsx tools/o1-golden.ts --record` only when a change to O1 results is intended and explained. Generated rooms are placeholders, not tuned or approved.
Simulator and sim-feeding world code use `M.*` from `combat/portable-math.js`, never native `Math.sin/cos/atan2/hypot/exp/pow`; run `node combat/tools/sync-portable-math.js` after editing it (see combat/CLAUDE.md).
Expedition layer: `src/expedition/` plans routes and chooses doors only (it is a `Navigator` for `WorldRunner`); it never picks a tactic. `tests/golden/expedition-runs.json` guards Chronicles; re-record with `npx tsx tools/expedition-golden.ts --record` only for an intended, explained change. `?scene=expedition` opens the planner screen.
Loot and loss: carried loot is at risk until camp. `src/expedition/loot.ts` tracks it, `src/expedition/settle.ts` is the only code that turns an expedition into a new save (bank once on extraction, one cache on death), and `validateInvariants` in `src/save/save.ts` guards the result. Never bank anywhere else.
Fog, gates and keys: `src/world/gates.ts` holds the gate states; a gate opens only through an `open` objective with an issued key (or by hand for a shortcut), never automatically. Fresh keys are never eligible; only keys banked at camp and issued for the expedition are. Save is version 2.
